# Examples

Example integrations using [Token Vault](https://tokenvault.uk).

| Example | Description |
|---------|-------------|
| [GitHub Repos Agent](github_repos_agent/) | Google ADK (Python) agent that lists a user's GitHub repos using a Token Vault credential |
| [Webhook](webhook/) | The reference Token Vault webhook (TypeScript): Node + tunnel, or Cloudflare Workers |
| [Webhook ngrok](webhook-ngrok/) | Legacy Python webhook (does not implement spec 2.10.0); use `webhook/` |
